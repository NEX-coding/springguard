AIC · AI+开源

SpringGuard

基于 Open Code Review 的 Spring 智能审查增强
确定性规则 × 可选 AI × 可复现评测

问题：Spring 审查的痛点

  • 事务自调用失效、缺 @Valid、MyBatis ${} 注入
  • 纯 LLM：不稳定、难复核、成本高
  • 纯静态工具：缺语义叙述与开源 Agent 生态

目标

  • 无模型也能稳定检出核心 Spring 缺陷
  • 可挂接上游 OCR + 本地 Ollama
  • 金标准评测，拒绝「模型自评」
  • 开源边界清晰：自研 vs 上游可核对

开源选型

上游

alibaba/open-code-review
确定性工程 × Agent
自定义规则包 · JSON 输出

为什么选它

可扩展、可本地模型、
二次开发切口清晰、
避免从零造审查引擎

方案架构

Spring 工程
  ├─ SpringGuard（自研静态规则）→ findings
  └─ OCR + rule.json（可选）   → findings
         └─ merge → eval → web

创新点（相对薄封装）

  • SpringGuard：Controller / Service / Mapper 确定性规则
  • 规则包：.opencodereview/rule.json 领域提示
  • 混合流水线：编排 + 归一化合并
  • 金标准评测：6 类缺陷 Recall
