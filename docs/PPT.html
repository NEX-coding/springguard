SpringGuard

基于 Open Code Review 的 Spring 智能审查增强
确定性规则 × 可选 AI × 可复现评测

参赛方向：AI 开发工具与开源协作

问题与场景

  • 事务自调用失效、缺 @Valid、MyBatis ${} 注入等高发
  • 纯大模型：不稳定、难复核；纯人工：成本高
  • 目标用户：Java / Spring 学生与中小团队

方案架构

Spring 工程 / 上传 ZIP
  ├─ SpringGuard（自研静态规则）→ findings
  └─ OCR + rule.json（可选）   → findings
         └─ merge → eval → Web :5193
